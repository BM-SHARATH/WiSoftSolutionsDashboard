# Dashboard website

## A responsive real dashboard website built with React and Tailwind CSS, featuring a fixed navbar, services, projects carousel, client testimonials, and contact form.

## Tech Stack

- **React** (with functional components & hooks)
- **React Router DOM** (for routing)
- **Tailwind CSS** (for styling and responsiveness)
- **Lucide React** / **React Icons** (for icons)
- **Vite** (for development server & build)
- **Other**: Custom assets/images

---

## Project Structure

```
src/
  assets/           # Images and icons
  components/       # Navbar, Footer, DashboardCard, etc.
  pages/            # About, Services, ClientsSection, Carousel, ContactUs, etc.
  App.jsx           # Main app with routes
  index.js
  ...
```

---

## Installation & Running Instructions

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   cd <project-folder>
   ```
2. **Install dependencies**

   ```bash
   npm install
   ```

   or

   ```bash
   yarn
   ```

3. **Start the development server**

   ```bash
   npm run dev
   ```

4. **Open in browser**
   - Visit [http://localhost:5173](http://localhost:5173) (Vite default)

---

## Build for Production

```bash
npm run build
```

or

```bash
yarn build
```

---

## Features

- Responsive layout for mobile, tablet, and desktop
- Fixed, interactive navbar with gradient background
- Services grid with icons
- Projects carousel with navigation
- Client logos and testimonials
- Contact form with map
- Footer with quick links and info

---

## Customization

- Update images in `src/assets/`
- Edit content in `src/pages/` and `src/components/`
- Adjust Tailwind classes for design tweaks
